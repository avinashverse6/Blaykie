Generated by `CslSpikeTest.goldenConverterComparison` in [CI run 43185206782](https://github.com/avinashverse6/Blaykie/actions/runs/43185206782), using the bundled citeproc-js, APA style and en-US locale. Each row compares one fixture in isolation: parenthetical, author-only plus suppress-author narrative, or plain-text bibliography. Italics, page/prefix and multi-item context are not compared. The 30 existing `apa-round2-golden.json` items are supplemented with a book, chapter and Gujarati author (33 items; 99 output comparisons).

Converter A is the debug default. Converter B is only an offline-tested JSON parser; it is not compared here. Results do not prove APA correctness. Differences are classified as **CSL APA or processor behavior** when no definite mapping error remains identified; that label also includes divergences from built-in formatting policy and requires further audit, not a claim of normative correctness. Corrected converter errors (DOI normalization and extra, blog-title and institution fallback, conference event place, edition and forthcoming) were fixed before this run.
