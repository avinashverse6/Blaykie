# Blaykie 1.2.0

## What's new

- **Documents:** Pick up where you left off, or rename or delete a saved document from the Documents list.
- **References at the end:** Turn on **Add to end** to add a bibliography automatically, with hanging indents and italics where appropriate. It updates as you add or remove citations.
- **Two ways to read:** Use **Mobile** for a continuous view or **Print** to see your work on pages. Tap a paragraph in either view to insert a citation.
- **More citation options:** Add a page, page range, chapter, paragraph, or section. Add words before or after the citation, omit the author from a parenthetical citation, or tap a highlighted citation to edit its saved options.
- **Redesigned Insert citation screen:** Search Zotero, select references, and preview your APA citation before inserting it.
- **Closer to your original document:** Pictures, thin rules, fonts, and paragraph spacing display more faithfully.

## Known limits

- Page breaks in Print layout are approximate and may differ from Word.
- Older citations without a saved session can be removed, but their options can't be edited.
- Custom CSL citation styles remain experimental and off by default.

## Upgrade note

Install 1.2.0 over 1.1.0 using an APK signed with the same signing key.

## Download

When 1.2.0 is published, download the single universal `Blaykie-v1.2.0.apk` and its matching `Blaykie-v1.2.0.apk.sha256` file from the release page. Keep them in the same folder and verify the download before installing:

```sh
sha256sum --check Blaykie-v1.2.0.apk.sha256
```

The command should report `Blaykie-v1.2.0.apk: OK`.
